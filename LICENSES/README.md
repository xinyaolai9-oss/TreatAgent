# Licensing scope

TreatAgent uses different licenses for different classes of material.

## Apache License 2.0

The root [`LICENSE`](../LICENSE) applies to original TreatAgent software,
including source code under `treatagent/` and `reproducibility/`, and original
project-authored Python or shell utilities under `data/`.

## Creative Commons Attribution 4.0 International

Original project-authored documentation, manuscript figures under
`assets/figures/`, and original result artifacts under `results/` are licensed
under the Creative Commons Attribution 4.0 International License (CC BY 4.0),
unless a file or directory states otherwise. See [`CC-BY-4.0.txt`](CC-BY-4.0.txt).

Attribution should identify the TreatAgent authors, link to this repository,
name CC BY 4.0, and indicate whether changes were made.

## Excluded third-party and derived material

The project licenses above do not relicense third-party datasets, database
content, pretrained models, checkpoints, software dependencies, trademarks,
or other externally sourced material. In particular, non-code artifacts under
`data/` remain subject to their source terms. See
[`THIRD_PARTY_NOTICES.md`](../THIRD_PARTY_NOTICES.md).

Where an artifact combines original TreatAgent material with third-party
content, both the applicable project license and the relevant upstream terms
must be followed.
